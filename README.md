# 🎵 Spotify Virality Prediction System

## 🌟 Overview
This project is an end-to-end Machine Learning pipeline and interactive dashboard that predicts the probability of a song going viral. By analyzing the "Audio DNA" of tracks (such as danceability, energy, and acoustic patterns) and engineering over 50 advanced features, this custom Stacking Ensemble model identifies exactly what makes a viral hit.


## ✨ Key Features
- **Offline Dataset Support**: Can dynamically generate data via Spotify API or seamlessly fall back to local offline datasets (`data/raw/dataset.csv`).
- **"Audio DNA" Feature Engineering**: Explodes 19 raw audio traits into 70 highly predictive dimensions, including Polynomial Interactions (Hype multipliers), Target Encodings, and Temporal Release metrics.
- **Advanced Stacking Ensemble ML**: Combines CatBoost, LightGBM, XGBoost, Random Forest, and Logistic Regression to capture complex non-linear nuances.
- **Explainable AI**: Integrates SHAP to uncover the "Viral Song Recipe"—telling you *why* a song is viral, not just *if*.
- **Interactive UI with Pipeline Runner**: Features a stunning Streamlit dashboard complete with a custom sidebar Pipeline Runner to rebuild your datasets and retrain your models dynamically on the fly!

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- pip package manager

### Installation

1. **Navigate to the directory:**
   ```bash
   cd spotify-virality-prediction
   ```
2. **Install required packages:**
   ```bash
   pip install -r requirements.txt
   ```

### Running the Dashboard & Pipeline
You can trigger the entire application from the frontend Streamlit dashboard:

1. **Launch the Dashboard:**
   ```bash
   python -m streamlit run frontend/app.py
   ```
2. **Use the Interactive Pipeline Runner:**
   - Open the left sidebar in the dashboard.
   - Adjust the **number of samples** you wish to train on.
   - Click the **🚀 Run Pipeline** button! The system will dynamically read from `data/raw/dataset.csv`, engineer 70 features, retrain all ML models, re-calculate the optimal thresholds, and refresh the dashboard UI—all automatically!

Alternatively, run the pipeline directly from the terminal:
```bash
python run_pipeline.py --num-songs 5000
```

## 🤖 Machine Learning Architecture
Our system evaluated several state-of-the-art algorithms:
- **CatBoost & LightGBM**: Handled the categorical features beautifully natively.
- **XGBoost**: Provided the highest individual baseline ROC-AUC score.
- **Random Forest**: Best generalizer to avoid overfitting.
- **Stacking Ensemble**: The final architecture uses a metamodel to combine the intelligence of all the base models above, achieving maximum predictive mastery.
